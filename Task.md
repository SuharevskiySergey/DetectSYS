# Beholder — tasks.md

> Рабочее техническое задание (ТЗ — техническое задание) и план реализации органического бехолдера в Blender и Unreal Engine 5.
>
> Статус: концепция механик согласована; моделирование, анимация, программирование и тесты ещё не выполнены. Задачи ниже — план, а не отчёт о готовой реализации.
>
> Принцип документа: **[УТВЕРЖДЕНО]** — решение пользователя; **[ПРЕДЛОЖЕНО]** — инженерная идея, ещё не утверждённая отдельно; **[ОТЛОЖЕНО]** — не входит в текущий этап; **[ТРЕБУЕТ ПРОВЕРКИ]** — может потребовать изменения ради работоспособности.

## 0. Краткая концепция и неизменяемые требования

- [x] [УТВЕРЖДЕНО] Существо полностью **органическое**, не робот и не механизм из металла. Внешняя схожесть сегментированных лап с Омнидроидом относится к характеру движения, а не к материалам и происхождению.
- [x] [УТВЕРЖДЕНО] Основное тело — сфера.
- [x] [УТВЕРЖДЕНО] В сфере мысленно вписан куб. **8 вершин** задают расположение восьми лап, **6 направлений нормалей к граням** — положения главного глаза.
- [x] [УТВЕРЖДЕНО] **8 лап по 10 сегментов** — 80 сегментов всего. Сегменты пока одинаковой длины.
- [x] [УТВЕРЖДЕНО] Лапы могут изгибаться пространственно во всех направлениях; сегменты телескопически втягиваются.
- [x] [УТВЕРЖДЕНО] На конце каждой лапы — один сферический малый глаз и три когтя; когти **никогда не отсоединяются**.
- [x] [УТВЕРЖДЕНО] Глазное навершие жёстко связано с последним сегментом; наведение осуществляется изменением позы лапы, не независимым шарниром глаза.
- [x] [УТВЕРЖДЕНО] Бехолдер ходит на четырёх лапах, четыре другие могут наблюдать и атаковать; может прыгать, катиться и ползать по стенам/потолку.
- [x] [УТВЕРЖДЕНО] Малые глаза испускают импульсные мгновенные лучи; не более двух лучевых атак одновременно.
- [x] [УТВЕРЖДЕНО] Главный глаз генерирует конус антимагии.
- [x] [УТВЕРЖДЕНО] При выводе из строя пяти лап бехолдер **нейтрализован, но жив и остаётся в сознании**.

## 1. Геометрия тела и посадочных мест

- [ ] Смоделировать центральную сферу и ориентирующий вписанный куб.
- [ ] Разметить направления 8 вершин: локальные координаты `(±R/√3, ±R/√3, ±R/√3)`, где `R` — радиус тела.
- [ ] Разметить 6 направлений главного глаза: `+X`, `−X`, `+Y`, `−Y`, `+Z`, `−Z` (ориентация осей — относительно локальной модели).
- [ ] Сделать 8 органических посадочных углублений для глазных наверший.
- [ ] [УТВЕРЖДЕНО, уточнение посадки] При полном втягивании **все 10 сегментов каждой лапы скрываются внутри тела**, но глазное навершие **не уходит внутрь полностью**: половина его сферы утоплена в посадочное углубление, а передняя половина остаётся снаружи. Ориентир глубины посадки — плоскость края гнезда проходит через центр сферы навершия (по её экватору); наружная полусфера направлена вдоль оси гнезда от тела.
- [ ] [УТВЕРЖДЕНО] В полностью сложенном состоянии **сегменты лап** не выступают из корпуса; выступающая наружная половина сферы каждого навершия является штатной частью внешнего габарита модели. Пересечения **скрытых сегментов внутри сферы разрешены**.
- [ ] Проверить габариты глаз и защитных когтей относительно оболочки тела при качении.
- [ ] [ТРЕБУЕТ ПРОВЕРКИ] Предусмотреть безопасное открытие глаза в углублении, чтобы веко и когти не пересекали корпус.

## 3. Малый глаз, когти и веко — один эталонный модуль ×8

### 3.1. Подтверждённая геометрия

- [x] [УТВЕРЖДЕНО] На конце лапы находится сферическое глазное яблоко.
- [x] [УТВЕРЖДЕНО] Вокруг глаза — **три органических когтя**.
- [x] [УТВЕРЖДЕНО] Каждый коготь движется в **своей плоскости**; три радиальные плоскости разнесены на **120°** вокруг оси глаза.
- [x] [УТВЕРЖДЕНО, уточнение концепции] Когти жёстко перемещаются по сферическим дугам **вокруг центра глаза**, не откидываясь на шарнире в основании. Расстояние основания до центра и угол когтя к местному радиусу постоянны; форма когтя не меняется.
- [ ] [ТРЕБУЕТ ПРОВЕРКИ] Окончательный диапазон новой сферической кинематики. В прототипе проверен технический ход **0–90° вокруг центра**; это не изменение угла когтя относительно радиуса и не окончательная приёмка диапазона.
- [x] [УТВЕРЖДЕНО] В закрытом состоянии основания когтей расположены на сфере, а их кончики сходятся **над поверхностью** в вершину трёхгранной пирамиды.
- [x] [УТВЕРЖДЕНО] Точки соприкосновения когтей со сферой задают треугольник, а его описанная окружность определяет **кольцевой край отверстия века**.
- [x] [УТВЕРЖДЕНО] Веко — **единая внешняя органическая сферическая оболочка** с изменяемым отверстием; внутренняя сфера — глаз.
- [x] [УТВЕРЖДЕНО] При раскрытии когтей отверстие увеличивается, при закрытии стягивается.
- [x] [УТВЕРЖДЕНО] Когти также служат опорой для ходьбы, позволяют цепляться за поверхности, колоть и резать.
- [x] [УТВЕРЖДЕНО] Коготь может независимо выполнять режущее движение, **оставаясь прикреплённым**. Глаз в это время может оставаться открытым благодаря независимому удержанию формы века.
- [ ] [ТРЕБУЕТ ПРОВЕРКИ] Геометрия описанной окружности лежит в плоскости трёх точек, а оболочка лежит на сфере: нужно согласовать реальную трёхмерную форму края отверстия и деформацию кожи. Не путать описанную плоскую окружность и произвольный кривой контур на сфере.
- [ ] [ТРЕБУЕТ ПРОВЕРКИ] Разработать **органическую** поддерживающую структуру края века; прежний вариант «металлического механизма фиксации» не подходит из-за уточнения, что существо полностью органическое.

## 5. Лучевые атаки малых глаз

### 5.1. Утверждённые параметры

| Параметр | Значение | Статус |
|---|---|---|
| Тип | Мгновенный импульсный луч | [УТВЕРЖДЕНО] |
| Дальность | 30 метров = 3000 см | [УТВЕРЖДЕНО, предварительный баланс] |
| Одновременно атакующих лучами глаз | Не более **2**, включая зарядку | [УТВЕРЖДЕНО] |
| Минимальная зарядка | **0,5 с** | [УТВЕРЖДЕНО] |
| Максимальная зарядка | **2,5 с** | [УТВЕРЖДЕНО] |
| Тестовое время зарядки | **0,5 с** | [УТВЕРЖДЕНО] |
| Перезарядка после реального выстрела | **6,0 с** | [УТВЕРЖДЕНО] |
| Максимальный разброс при 0,5 с | **±3,0°** | [УТВЕРЖДЕНО] |
| Максимальный разброс при 2,5 с | **±0,3°** | [УТВЕРЖДЕНО] |
| Зависимость разброса | Линейная | [УТВЕРЖДЕНО] |
| Мощность пробивания | Повышается с зарядкой | [УТВЕРЖДЕНО, численные параметры не заданы] |
| Фиксация направления перед выстрелом | Предлагалось за 0,3 с | [ПРЕДЛОЖЕНО] |

Формула максимального разброса для `t` в диапазоне от 0,5 до 2,5 секунды:

```text
SpreadDegrees(t) = 3.0 - 1.35 * (t - 0.5)
```

Формула относительной пробивной силы (численные границы пока неизвестны):

```text
Penetration(t) = Pmin + ((t - 0.5) / 2.0) * (Pmax - Pmin)
```

### 5.2. Поведение

- [ ] Каждый глаз независимо обнаруживает и выбирает цель.
- [ ] Общее управление разрешает не более двух одновременных процедур лучевой атаки.
- [ ] Перед зарядкой учитывать видимость, дальность, направление и перспективу попадания.
- [ ] Зарядку делать визуально заметной, чтобы противник мог уклониться.
- [ ] Направление луча перед выстрелом фиксировать на настраиваемый интервал; в момент выстрела делать проверку попадания по фактической геометрии.
- [x] [УТВЕРЖДЕНО] По скрывшейся цели разрешён выстрел в последнюю видимую или предполагаемую точку — без знания её реального положения за укрытием.
- [x] [УТВЕРЖДЕНО] Луч может пробивать препятствия в зависимости от мощности и материала.
- [x] [УТВЕРЖДЕНО] Длительная зарядка повышает **и точность, и пробивную силу**.
- [x] [УТВЕРЖДЕНО] При срочной необходимости лапы для движения/опоры **зарядка прерывается немедленно**, выстрела нет и новая шестисекундная перезарядка не начинается; слот атаки освобождается.
- [ ] Блокировать собственные лучи, пересекающие действующий конус антимагии.
- [ ] [ОТЛОЖЕНО] Настоящие отверстия в любом месте препятствий, физическое разрушение, материалы уровня и обломки; к бехолдеру вернуться после базовой реализации.
