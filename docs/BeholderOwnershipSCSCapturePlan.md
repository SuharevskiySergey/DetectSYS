## Предлагаемый raw snapshot (не effective-template oracle)

Для каждого admitted Blueprint layer сохранить отдельно:

1. BP identity, stored GeneratedClass и SimpleConstructionScript wrappers; generated-class SCS/handler и superclass evidence — отдельно, не подстановка по имени или общему package.
2. SCS actual outer observation и форму ownership (class/legacy BP/unsupported). Для class outer нужны generated-by relation и подтверждённая owner identity, а не только FString path.
3. Stored RootNodes и AllNodes как отдельные ordered списки с source index. Их union не подменяет оба оригинальных списка. Missing/duplicate/external/null entries сохраняются как evidence/gap.
4. Для каждого admitted node: identity/outer, GUID/raw variable name, class/template wrappers; literal flags только после resolved/valid/template/package checks. Attachment fields `AttachToName`, `ParentComponentOrVariableName`, `ParentComponentOwnerClassName`, `bIsParentComponentNative` — raw labels, не разрешённая связь.
5. ChildNodes edges с provenance (source node/index/target observation). Cycle/duplicate edges не удалять; node payload посещать один раз. Nodes только в AllNodes и nodes только в child/root edges отражать явно, не ремонтировать registry.

Каждый pointer сначала копируется как wrapper с проверкой IsResolved; никаких Get/path/Cast до admission. Reflected direct-storage schema обязана проверять property kind/inner/ArrayDim/getter перед чтением; неизвестная layout — refusal, не getter fallback. Ранее используемые бюджеты других readers не переносятся автоматически: до реализации отдельно определить node/edge/depth/text/array-admission bounds, partial-retention semantics и aggregate budget по всем layers. Это не обещание ограничения peak allocation/serialized bytes.

## Fail-closed граница рекомендаций

- Не вызывать GetAllNodes, FindSCSNode, GetActualComponentTemplate, ValidateGuid, name setters, handler creators, CDO getters или compiler в raw capture. Не создавать GUID вместо missing GUID.
- Нулевые own overrides не означают отсутствие inherited overrides, а пустой AllNodes не означает пустой SCS при непустых roots.
- Null/unknown template не означает default visibility. Неизвестный owner/GUID, дубликаты или несогласованные hierarchy tracks подавляют selection recommendation.
- Config gate пока NotCaptured. Не читать config helper с побочными cache effects как часть raw contract; отдельная observation policy нужна до effective-selection claims.
- Native/UCS components, cooked instancing data, instance overrides, full template serialization и восстановление не покрываются этим SCS-only планом.
- complete/engineIdentityVerified/reparentReady остаются false. Полная backup/restore policy требуется отдельно; этот DTO не восстановительный архив.
